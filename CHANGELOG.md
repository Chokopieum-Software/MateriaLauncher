## Alpha 0.2.0

### Русский

- В Windows вход через Microsoft сначала открывает системное окно. Если войти через него не удалось, открывается браузер. После ответа Microsoft лаунчер возвращается на передний план.
- Офлайн-аккаунты можно создавать после входа в Microsoft с лицензией Minecraft Java. При переключении профилей игра получает токен выбранного Microsoft-аккаунта.
- Каталог подгружает результаты при прокрутке. Модпаки можно искать независимо от выбранной сборки.
- Статус входа и фильтры каталога стали заметнее в тёмной теме.
- В настройках доступна полная история версий. Перед установкой обновления можно прочитать, что изменилось.

### English

- On Windows, Microsoft sign-in opens the system dialog first and falls back to the browser if needed. The launcher returns to the foreground when Microsoft responds.
- You can create offline accounts after signing in with a Microsoft account that owns Minecraft Java. When you switch profiles, the game receives the selected Microsoft account’s token.
- The catalog loads more results as you scroll. You can search for modpacks independently of the selected instance.
- Sign-in status and catalog filters are easier to read in dark mode.
- Settings now includes the full release history. You can read what changed before installing an update.

## Alpha 0.1.0

### Русский

- В каталоге можно подобрать совместимые моды для сборки и установить их из корзины.
- При создании сборки загрузчик модов можно выбрать из списка с иконками.
- В Windows доступны экспериментальная тема Acrylic и обновление лаунчера из приложения.

### English

- You can find compatible mods for an instance in the catalog and install them from the cart.
- When creating an instance, you can choose a mod loader from a list with icons.
- Windows users can enable the experimental Acrylic theme and update the launcher from the app.
